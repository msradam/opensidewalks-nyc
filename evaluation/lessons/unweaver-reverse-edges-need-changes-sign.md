Unweaver adds a reverse copy of every input feature, and copies its incline unchanged unless the graph is built with `--changes-sign incline`.

This layer already holds both directions of every edge, so without the flag each direction exists twice, once with the right sign and once with the wrong one, and a 9% climb passes as a 9% descent. On 840 Brownsville routes the re-implemented search and Unweaver agreed on found or not found in all 840 either way, but 10 Unweaver routes were 13 m or 47 m shorter through such an edge. Built with the flag, all 826 routes found by both have the same length to 0.1 m. Always build with `unweaver build PROJECT --changes-sign incline`. Evidence: research_notes/compare/results/unweaver_bk16.json and unweaver_bk16_without_changes_sign.json.
