# Routes checked over orthoimagery by a language-model rater

2026-10-03. The route lengths are from the final build (commit `2442db2`). The per-edge descriptions were written on the build at `6d7cc72`, before the George Washington Bridge tower fix in `2442db2`; the note at the end gives the differences. The images were drawn over NY State "Latest" orthoimagery (about 30 cm here), which the pipeline does not use. The images are not published, because no licence statement for that imagery was found; their file names are kept below for reference.

The rater was one Anthropic Claude model instance, run through Claude Code and given the route images. The exact model version was not recorded. No person rated these routes, and nothing was checked on the ground. The check shows whether a route lies on sidewalks, crossings, paths and bridge decks; it cannot see a kerb ramp. Where a row says an edge reads too steep, the steepness comes from this pipeline's own LiDAR heights at the edge's two nodes, not from any OSM tag.

Colours: cyan sidewalk, yellow crossing, green footway (bridge decks and park paths are footways), magenta steps, red street centreline. No wheelchair route below has a magenta or red segment.
